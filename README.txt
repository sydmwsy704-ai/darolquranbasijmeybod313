سامانه دارالقرآن بسیج میبد — نسخه ۳ (آماده اتصال به Supabase)
==============================================================

محتویات:
- index.html: سایت عمومی و فرم پیش‌ثبت‌نام
- admin-dashboard.html: پنل ورود مدیر و مدیریت درخواست‌ها
- admin.html: ابزار ویرایش محتوای سایت (خروجی JSON)
- site-content.json: محتوای پیش‌فرض سایت
- supabase-config.js: محل تنظیم Project URL و anon/public key
- supabase-setup.sql: ساخت جدول‌ها و سیاست‌های امنیتی پایگاه داده

نکته مهم:
تا زمانی که Supabase ساخته و تنظیم نشده، فرم عمومی عمداً اطلاعات شخصی را ذخیره نمی‌کند.
نسخه ۳ پس از تکمیل مراحل راه‌اندازی، درخواست‌ها را در پایگاه داده مرکزی ذخیره می‌کند.
این بسته به‌تنهایی هنوز یک سایت آنلاین نیست و به اطلاعات پروژه Supabase و انتشار روی Netlify نیاز دارد.

راه‌اندازی:
۱) در https://supabase.com یک پروژه جدید بسازید.
۲) در Project Settings > API، مقدار Project URL و anon/public key را بردارید.
۳) فقط این دو مقدار را در supabase-config.js جایگزین کنید.
   هرگز service_role key یا رمز عبور مدیر را در فایل‌های سایت قرار ندهید.
۴) در Supabase > SQL Editor، تمام محتوای supabase-setup.sql را اجرا کنید.
۵) در Authentication > Users یک کاربر مدیر بسازید (ایمیل مدیر و رمز قوی).
۶) شناسه UUID کاربر ساخته‌شده را از فهرست Users کپی کنید.
۷) در SQL Editor این دستور را با UUID واقعی اجرا کنید:
   insert into public.admin_users (user_id) values ('UUID-کاربر-مدیر');
۸) پوشه پروژه را روی Netlify منتشر کنید.
۹) آدرس /admin-dashboard.html مسیر ورود مدیر است.

نکات امنیتی:
- anon key برای قرارگرفتن در مرورگر طراحی شده و به‌تنهایی مجوز خواندن ثبت‌نام‌ها نمی‌دهد؛ RLS این دسترسی را محدود می‌کند.
- فقط کاربرانی که UUID آن‌ها در admin_users ثبت شده است می‌توانند درخواست‌ها را بخوانند/ویرایش/حذف کنند.
- هیچ‌وقت service_role key را در فایل‌های عمومی یا چت ارسال نکنید.
- اطلاعات افراد را فقط برای هدف ثبت‌نام جمع‌آوری کنید و دسترسی پنل را محدود نگه دارید.
- پیش از استفاده عمومی، یک ثبت‌نام آزمایشی و ورود مدیر را بررسی کنید.
- برای نگهداری بلندمدت، پشتیبان‌گیری و سیاست حریم خصوصی مشخص کنید.

ویرایش محتوا:
- admin.html برای ویرایش متن‌ها، تصاویر و دوره‌ها و دانلود site-content.json است.
- برای تغییر مستقیم ظاهر/رفتار، از VS Code و فایل‌های HTML/CSS/JS استفاده کنید.
- برای دیدن تغییرات در کامپیوتر از Live Server استفاده کنید.
